# Brand Spec: Striplys Window Talks (IKEA × Peanuts)

## Visual Identity
A synthesis of Scandinavian minimalism (IKEA) and nostalgic, hand-drawn emotionality (Peanuts).

## Palette (OKLch)
- `--bg`: `oklch(97% 0.015 80)` (Warm Paper / Cream)
- `--surface`: `oklch(100% 0 0)` (Pure White)
- `--fg`: `oklch(20% 0.02 240)` (Ink Black / Deep Charcoal)
- `--muted`: `oklch(65% 0.02 80)` (Warm Grey)
- `--border`: `oklch(20% 0.02 240)` (Solid Ink Line)
- `--accent`: `oklch(55% 0.18 250)` (IKEA Blue)
- `--accent-soft`: `oklch(88% 0.15 90)` (Peanuts Yellow / Woodstock)

## Typography
- **Display**: `Poppins`, sans-serif (Bold, friendly, modern)
- **Body**: `Montserrat`, sans-serif (Clean, geometric, accessible)
- **Comic/Meta**: `ui-monospace`, monospace (Used for "hand-written" feel technical notes or captions)

## Layout & Posture
- **Borders**: 2px solid ink lines for primary containers and figures.
- **Radii**: Soft 12px corners on cards, but sharp 0px on comic-strip style panels.
- **Shadows**: No soft shadows; use 4px hard offsets (comic style) if elevation is needed.
- **Motif**: The "Striplys Window" 4x4 grid used as a recurring visual separator.
